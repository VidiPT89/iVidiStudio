# Processo — Pedido de suporte

**Piso:** Piso 6 · Sucesso do Cliente

## Passos

1. Identificar produto e cliente (só `cliente-ref`).
2. Procurar resposta nas FAQs.
3. Se for bug: criar ticket para `05-qa` com `templates/`.
4. Redigir resposta em PT-PT (ou EN se o cliente escreveu em inglês).
5. Mover para `aguarda-aprovacao/` com `acao-aprovacao: enviar resposta a CLI-NNNN`.

## Lembra-te

- Atualiza o `Histórico` do ticket a cada passo.
- Ações do portão humano → `elevador/aguarda-aprovacao/`.
- Sem dados pessoais em texto (RGPD).
