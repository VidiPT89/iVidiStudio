# Processo — Escrever uma spec

**Piso:** Piso 3 · Produto & Design

## Passos

1. Descrever o problema e para quem (sem soluções ainda).
2. Definir métrica de sucesso.
3. Escrever critérios de aceitação verificáveis (Dado/Quando/Então).
4. Anexar fluxos ou links Figma.
5. Criar ticket para `04-engenharia` com a spec em referência.

## Lembra-te

- Atualiza o `Histórico` do ticket a cada passo.
- Ações do portão humano → `elevador/aguarda-aprovacao/`.
- Sem dados pessoais em texto (RGPD).
