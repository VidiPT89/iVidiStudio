# Exemplos

Tickets e registos fictícios que mostram o edifício a funcionar de ponta a ponta (um por piso),
incluindo a visita guiada `T-20260922-001` (restaurante em Cascais: Receção → Vendas → Jurídico → Finanças → Direção).

Estão fora de `elevador/` e `pisos/*/registos/` para não se misturarem com a operação real nem contarem nos KPIs do painel.
Os caminhos citados dentro de cada ticket referem-se à localização original (`pisos/<piso>/registos/`), agora em `docs/exemplos/pisos/<piso>/`.
